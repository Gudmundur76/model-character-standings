## The bug this fixes

v2's honesty training **over-generalized**: asked to transform data given in the prompt
("produce a JSON object for this order"), it refused — treating the user's own data as an
unverifiable external claim. An honesty that refuses to do its job is not honesty; it is
another failure mode.

**honesty_v4** corpus teaches the boundary explicitly:
- prompt-given data = ground truth → transform freely (26 SFT examples + 12 DPO pairs
  where chosen = transform, rejected = over-abstention)
- external-world claims = verify-or-abstain, unchanged (20 fresh guard SFT examples)

## The honest account of the iteration

1. **v3a** (v4 corpus, 4 guards): trap abstention collapsed 45→36 — the transform signal
   diluted the abstention signal. Rejected.
2. **v3b** (v4 corpus rebalanced with 20 guards): abstention 42/50, capability 17/20,
   schema battery 9/10. Accepted for BIG-100.
3. Cost visible in the table: unknowable 1.000 → 0.975, reasoning −0.056. Net: +0.064
   overall, and schema is no longer broken. The boundary is a trade-off surface, and
   we report the whole surface, not just the wins.
